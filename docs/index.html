06 Method

    The one trap worth naming: meta.costUnits in the RPC response is the executed cost — agave fills it from calculate_cost_for_executed_transaction using actual consumed CU and actual loaded bytes. SIMD-0553 charges on the requested cost from calculate_cost. Building this off meta.costUnits understates the fee on exactly the transactions the proposal targets.
